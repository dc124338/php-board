PHP掲示板

概要
PHPとMySQLを使用して作成した、投稿・編集・削除機能を備えた掲示板アプリケーションです。投稿ごとに設定したパスワードを使用して、編集や削除を行えます。

使用技術
PHP 8.4
MySQL
HTML
PDO（データベース接続）

主な機能
投稿機能：名前、コメント、パスワードを入力して投稿
一覧表示機能：投稿ID、名前、コメント、投稿日時を表示
編集機能：投稿IDとパスワードを確認し、投稿内容を編集
削除機能：投稿IDとパスワードを確認し、投稿を削除

工夫した点
htmlspecialchars() を使用し、投稿内容を画面に表示する際のXSS対策を意識しました。
投稿・更新・編集・削除の処理を分け、操作ごとに適切な処理が実行されるようにしました。
データベース接続処理と画面表示処理を別ファイルに分け、コードの見通しや保守性を意識しました。

起動方法
PHPとMySQLをインストールします。
MySQLにデータベース tb280289db を作成します。
db.php にローカル環境のデータベース接続情報を設定します。
プロジェクトのフォルダで以下のコマンドを実行します。
php -S localhost:8000
ブラウザで http://localhost:8000/board.php にアクセスします。
